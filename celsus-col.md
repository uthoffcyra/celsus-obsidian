# celsus-col

This is a custom callout system I made for display different media, mostly books I'm reading. It keeps the cover image on the left, while placing a quoted element with relevant information at the right.

The 'plus' button is implemented using the [Meta Bind](https://github.com/mProjectsCode/obsidian-meta-bind-plugin) plugin.

## Example Markdown

```md
> [!celsus-col]
> ![[file-20251105143954533.png]]
> > ## Basic Info
> > **Author:** Homer
> > **Written:** 8th century BC
> > 
> > **Pages Read:** 137/223 `BUTTON[plus]`
> > 
> > **Date Started:** Nov 2nd, 2025
> > **Date Finished:** In Progress
```
