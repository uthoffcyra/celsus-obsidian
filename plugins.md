# Plugins

Here's a list of the plugins I have enabled on my vault.

## Core Plugins

- Backlinks
- Bases
- Command Palette
- Daily Notes
- Files
- Footnotes
- Graph View
- Outgoing Links
- Page Preview
- Quick Switcher
- Search
- Templates
- Word Count
- Workspaces

## Community Plugins

- [Columns](https://github.com/tnichols217/obsidian-columns)
  - Really useful for making quick columns of different elements, especially putting images side by side so they don't take up as much space.
- [Contextual Typography](https://github.com/mgmeyers/obsidian-contextual-typography)
- [Custom Attachment Location](https://github.com/RainCat1998/obsidian-custom-attachment-location)
- [Custom File Explorer Sorting](https://github.com/SebastianMC/obsidian-custom-sort)
  - Vital to my vault. It means I don't have to prefix folders with numbers, and that I can sort daily notes from newest first.
- [Furigana](https://github.com/uonr/obsidian-furigana)
  - I'm a Japanese major, so this is very useful for studying Kanji.
- [Iconic](https://github.com/gfxholo/iconic)
- [Image Context Menus](https://github.com/NomarCub/obsidian-copy-url-in-preview)
- [Inline Spoilers](https://github.com/logonoff/obsidian-inline-spoilers)
- [Kanban](https://github.com/mgmeyers/obsidian-kanban)
  - Used for handling all of my personal projects. Each card can link to their own note and be dragged between columns.
- [Meta Bind](https://github.com/mProjectsCode/obsidian-meta-bind-plugin)
  - I'm starting to use this more, slowly, making my notes more interactive.
- [Smart Typography](https://github.com/mgmeyers/obsidian-smart-typography)
